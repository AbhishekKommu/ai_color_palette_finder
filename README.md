# AI Color Palette Finder

Flutter app: pick an image (gallery/camera) -> get its dominant color palette
(k-means), color details (HEX/RGB/HSL/name), color-theory suggestions
(complementary, analogous, triadic...), an AI-style palette insight, and a saved history.

## Run
```bash
flutter create . --project-name ai_color_palette_finder
rm -f test/widget_test.dart     # default test generated by flutter create
flutter pub get
flutter run -d chrome
```

## Camera / gallery permissions
- iOS: add `NSCameraUsageDescription` and `NSPhotoLibraryUsageDescription` to `ios/Runner/Info.plist`.
- Android: works out of the box with `image_picker`.

## Tests
```bash
flutter test
```
